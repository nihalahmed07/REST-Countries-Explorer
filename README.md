# 🌍 REST Countries Explorer

A simple TypeScript project that uses the REST Countries API to display countries and filter them by name or region.

## 🔧 How to Run

1. Clone this repo
2. Run `tsc` to compile TypeScript
3. Open `index.html` in your browser

## 🚀 Features

* Search by country name
* Filter by region
* Responsive and minimal design

Made with ❤️ using TypeScript
